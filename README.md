# E-Learning Management System with Certificate Generation

A B.Tech CSE mini project built with Python Flask.

## Features
- Student registration and login
- Course listing and enrollment
- Course completion
- Quiz score field
- PDF certificate generation
- Responsive basic UI

## Technology
- Python
- Flask
- SQLite
- HTML/CSS
- ReportLab

## Run
```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000/`
